# 决策：六周可视化的视觉身份策略（2026-09-20）

已实施：每周一个独立视觉身份；共享文件只收敛工艺底线，不收敛配色。

## 问题
- 六个缺周（2026-08-11 ~ 2026-09-15）要各写一份 `02_exploratory_visualization.qmd`：站点外壳 [styles.css](../../assets/styles.css) 与 2026-08-04 先例都用深靛蓝 `#100e74` + 绿 `#0e8056`。
- 维护者要求「美学自己定，不要趋同化」：既不照抄先例，也不要六周一个模板复制六份。

## 决策
- 每周一个视觉身份：配色 + 图表家族 + 版式签名三者组合各不相同；本周配色在 qmd 顶部声明。
- `assets/tt_theme.R` 只沉淀工艺底线：本机可用字体栈、标题 / 副标题 / 脚注位与左对齐、网格与留白尺度、导出参数（dpi / 尺寸 / 背景）、禁用清单（饼图 / 双 Y 轴 / 彩虹色 / 重叠标签 / 图例 > 6 级）、图内英文。
- 配色不作主题文件的唯一来源，避免「只换颜色、版式照旧」的假多样。
- 反趋同可检查：每周回报「主色 hex + 图表家族 + 版式签名」，六行不得重复或近似。
- 站点脚本当时不动：`code/update_site.R` 只认 `output/02_exploratory_visualization.html`；该规则已于同日改为「02 优先、回退 01」，见 [site-index-all-weeks](2026-09-20-site-index-all-weeks.md)。

## 替代方案
- 六周统一站点靛蓝 / 绿：与已发布周一致，但与「不要趋同化」直接冲突。
- 六周统一米白 / 森林 / 锈红：六周之间仍然同构，且与站点外壳割裂。
- 不给共享底线、每周自由发挥：禁用图形与不可读标签会流入产物，返工成本转嫁给验收。
- 把六周配色全部写进 `assets/tt_theme.R`：单一来源便于统一，但正是趋同化的实现方式。

## 影响
- 站点侧边栏会并列七种风格差异明显的周：这是本决策的预期结果，不是缺陷。
- 验收必须逐图打开看（`read_image`），不能只看代码、文件大小或渲染 exit code。
- [weeks/README.md](../../weeks/README.md) 的模板仍是参考而非强制；硬约定只有 YAML 结构、契约文件名与路径口径。

## 追加约束：排版纪律（维护者 2026-09-20 口述，非可选）

- 字号阶梯单调递减且相邻可辨：标题 > 副标题 > 轴标题 > 轴标签 > 注释 > 脚注；全图字号种类 ≤ 6 级。
- 字体家族 ≤ 2 套（标题一族、数据与轴一族），不混第三套。
- 零重叠：文字互压、文字压数据点（有引导线的注释除外）、图例压面板、标签出画布，一律修掉。
- 层次不可错位：标题说洞察、副标题说口径、脚注说来源与剔除原因；注释与脚注不得抢标题的视觉权重。
- 自检必看两档：原始尺度 + 缩略图（长边 ≈ 600 px）；缩略图读不清标题或可见压盖 = 不通过。
- 落地方式：字号阶梯与家族上限写进 `assets/tt_theme.R` 的默认值，验收按同一判据逐图执行。
## 追加约束：产物洁净度（维护者 2026-09-20 口述）

- 渲染产物里不得出现内部笔记：排版自检小节、审计表与判定行、口径校验表、变更与缺陷记录、面向维护者的过程说明。
- 允许保留面向读者的数据方法与口径说明：构成比口径、样本链（raw → plotted）、数据异常提示、图注来源与剔除原因。
- 落地方式：自检 chunk 设 `#| include: false`（或 `output: false`），检查仍进渲染日志、`stopifnot` 硬闸保留；内部说明改写为 R 注释或 HTML 注释 `<!-- -->`。
- 验收方式：逐周 grep 产物 HTML，确不含「排版自检 / 越阶 / 上限 / tt_audit / TT_TYPE / 写死字号 / 缺陷 / 变更记录」等字样。
- 副作用是已记录的 HTML 字节数失效，属预期：字节数不作为不可变契约，产物内容洁净优先。
## 追加约定：源码展示与页面重量（2026-09-20 核实）

- 源码展示：报告 chunk 一律 `#| echo: false`，页面不显示 R 源码。判据是产物中 `<pre` 与 `class="sourceCode` 计数为 0——**字面 grep 与精确类名匹配都会假阴性**（Quarto 把 `<-` 转义成 `&lt;-`、`|>` 转成 `|&gt;`），2026-09-08 曾因此漏检：三个绘图块缺 `echo: false`，`code-fold: true` 把源码折进 `<details>`，已补齐并重渲染。
- 页面重量预算按 MiB 计：单页 `TT_HTML_MAX_MB = 6`（6 MiB）、单张内嵌 PNG `TT_PNG_MAX_MB = 2`；超预算时先降大画幅图的 `fig-dpi`（下限 `TT_DPI_FLOOR = 160`），再减画布或分层，不得靠继续降清晰度硬压。
- 内部笔记清理的判据是「渲染后的正文文本」，不是源码：自检 chunk 用 `include: false` 隐藏，源码里出现 `tt_audit` / `TT_TYPE` 不算泄漏。
